<NOX> **NOX — Developer / Designer Onboarding**

**What this is:** NOX is a fully open-source Fabric client for **Minecraft 26.3**, built for DonutSMP. Java 25, Fabric Loom, custom GUI/HUD, ~130 modules, premium licensing, Discord integration.

**Repo:** https://github.com/neuberghero-debug/nox
**Download:** GitHub Releases → `nox-0.1.0-alpha.jar` → drop into a Fabric 26.3 mods folder.

**Layout:** `src/main/java/dev/noxclient` — `module/` modules, `gui/` screens+helpers, `hud/` widgets, `settings/` typed settings, `discord/` Rich Presence, `premium/` licensing, `util/TamperGuard` (always on, never exposed as a module).
<NOX> 
<NOX> **Build & test — read this first**
• `bash tools/devloop.sh` — build → `nox_doctor` static checks → atomic deploy to the Modrinth NOX profile. Never `cp` onto the deployed jar.
• `python3 tools/nox_doctor.py` must pass (0 errors) before anything ships — it validates mixins, jar integrity, TamperGuard signature, assets.
• Runtime testing is mandatory, not optional: `tools/relaunch.sh`, then drive the client via `python3 tools/noxctl.py "gui|shot|state|toggle|set|click X Y [B]"`.
• Every module must actually *work* in-game — "compiles" is not "done".

**Module conventions**
• Every module: useful typed `Setting`s, `status()` one-liner showing live state (e.g. `ESP [on] 0 entities tracked`).
• Toggle **and** Hold activation modes; keybinds are NOX-internal (separate from MC keys).
• Animations are delta-time based — never fixed per-frame steps. Colors are full ARGB.
• 26.3 API quirks: `Identifier` (not ResourceLocation), `GuiGraphicsExtractor`, SDL scancodes, endpoint-based `blit`. See `AGENTS.md` in the repo — it lists every trap we already hit.
<NOX> 
<NOX> **Design system (must match)**
• Palette: bg `#0D0F14`, panel `#141821`, card `#1C222E`, accent `#8B5CF6` (theme-cyclable), text `#E6EAF2` / muted `#8B93A7`.
• Components: rounded everything (r 10–16), subtle `rgba(255,255,255,0.08)` borders, NanoVG glow/vignette/sheen pass, glassmorphism over solid black.
• GUI modes: Cards / Compact / Sidebar / Panels (floating columns + top pill) / Hub (sidebar + tiles) — new screens must respect the mode system and `Interface` settings.
• Reference direction: modern high-end clients (Rise, Novoline, Linear-style dark UI) — **inspired, never cloned 1:1**.

**Allowed / not allowed**
• ✅ Modules, HUD widgets, themes, cosmetics, addons, docs, bug reports, UI/UX design, marketing assets.
• ❌ No secrets/keys/tokens in the repo, no external payload downloads, no code that harms users' machines, no ripping other clients' assets/names.
• TamperGuard stays hidden and always-on — don't wire it into module lists.

**Contribute:** fork → PR against `main` → describe what you tested at runtime. Questions → this channel or a ticket in <#1570449832496074956>. Active areas: module polish, NanoVG effects, HUD widgets, docs.
